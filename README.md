# 마케팅 컨설팅 웹사이트 [MarketWith]

마케팅 컨설팅 회사 컨셉의 웹사이트

## 배포 사이트
[배포 사이트로 이동하기](https://marketwith.netlify.app/)

## 주요 기능

### 1️⃣ 회사소개 및 기본 정보 - `ABOUT`
- `회사소개`, `ABOUT US` 회사 기본 정보와 홍보 페이지
- `찾아오시는 길` 회사 위치 정보 맵으로 제공

### 2️⃣ 마케팅 서비스 소개 - `마케팅 서비스`
- `마케팅 서비스` 제공 서비스 간단히 소개
  - `사진 촬영 / 영상 제작` ~ `체험단 마케팅` <br/> 서비스 상세 소개 및 성과 예측 시뮬레이터 기능 제공

### 3️⃣ AI 마케팅 고민 진단 기능 - `AI 진단`
-  AI로 마케팅 고민을 간단히 정리 및 진단해볼 수 있는 기능 제공

### 4️⃣  업체 포트폴리오 확인 - `포트폴리오`
- 업체 포트폴리오를 카드 형식으로 확인할 수 있는 페이지 제공

### 5️⃣ 고객지원 및 컨설팅 신청 기능 - `고객지원`
- `컨설팅 신청` 컨설팅 견적 상담을 신청하고 신청 메일과 관리자에게 답변 받을 수 있는 기능 제공
- `문의 게시판` 질문을 남기고 관리자에게 답변 받는 1:1 게시판 기능 제공

### 6️⃣ 관리자 페이지
- `관리자 로그인` 관리자 아이디/패스워드 입력으로 로그인 기능 제공
- `관리자 대시보드` 문의 게시판 및 컨설팅 신청 페이지 신청내역을 확인하고 답변을 작성할 수 있는 기능 제공
